
# Bites Cafe ☕

Bites Cafe is a responsive café website designed to provide users with an interactive online browsing experience. It showcases café menu items, special offers, and contact information using HTML5, CSS3, and JavaScript.

## Features

- Home, Menu, Offers, and Contact sections.
- Interactive menu filtering (All, Drinks, and Pastries).
- Light and dark mode toggle.
- Interactive menu item selection.
- Order price calculation.
- Discount calculation.
- Reservation form with input validation.
- Special notes character counter.
- Café opening hours and information.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Locate the `index.html` file.
4. Open it in your web browser.
5. Explore the website and its interactive features.

No additional installation is required.
